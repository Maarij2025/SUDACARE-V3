# SUDACARE V3 — نظام متجر وإدارة فعلي

هذه النسخة تنقل المشروع من LocalStorage إلى:
- خادم Node.js
- قاعدة بيانات SQLite حقيقية
- تسجيل دخول للإدارة بجلسة آمنة
- API للمنتجات والتصنيفات والطلبات
- إدارة مخزون مشتركة
- لوحة إدارة للمنتجات والمخزون والطلبات والتصنيفات
- PWA قابلة للإضافة للشاشة الرئيسية للهاتف

## المتطلبات
Node.js 22.5 أو أحدث.

## تشغيل الكمبيوتر
1. افتح الطرفية داخل مجلد المشروع.
2. شغّل:
   `npm start`
3. افتح:
   `http://localhost:3000`

## بيانات الدخول الأولى
البريد:
`admin@sudacare.local`

كلمة المرور:
`ChangeMe123!`

غيّر كلمة المرور/بيانات الإدارة قبل أي استخدام فعلي.

يمكن تغيير بيانات البداية عبر:
`SUDACARE_ADMIN_EMAIL`
`SUDACARE_ADMIN_PASSWORD`

## استخدامه من الهاتف
الهاتف لا يشغّل خادم Node هذا بنفسه عادةً. بعد نشر المشروع على استضافة، افتح الرابط من الهاتف واضغط "إضافة إلى الشاشة الرئيسية"، وسيعمل كتطبيق PWA.

للتجربة داخل نفس شبكة Wi-Fi:
- شغّل `npm start` على كمبيوتر.
- اعرف عنوان IP للكمبيوتر.
- افتح من الهاتف: `http://IP-الكمبيوتر:3000`
- تأكد أن جدار الحماية يسمح بالمنفذ 3000.
