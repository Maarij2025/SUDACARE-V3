# SUDACARE V3 — نظام متجر وإدارة فعلي

هذه النسخة تستخدم خادم Node.js وقاعدة بيانات SQLite وتدعم متجرًا ولوحة إدارة ومخزونًا وطلبات وPWA.

## المتطلبات
Node.js 22.5 أو أحدث.

## التشغيل
`npm start`

## بيانات الدخول الأولى
البريد: `admin@sudacare.local`

كلمة المرور: `ChangeMe123!`

غيّر بيانات الإدارة قبل الاستخدام الفعلي. يمكن تحديدها عبر `SUDACARE_ADMIN_EMAIL` و`SUDACARE_ADMIN_PASSWORD`.
